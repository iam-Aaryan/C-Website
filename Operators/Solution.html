Answer 1


#include <stdio.h>
void main()
{
  int x=10,y ;
  y = ++x ;
  printf("%d",y);
}
Output :

11

Explanation : In pre - increment the value is increased by 1 before it is used in an expression

Answer 2


#include <stdio.h>
void main()
{
  int x=10,y ;
  y = x++ ;
  printf("%d",y);
}
Output :

10

Explanation : In post - increment the value is used first and then increased by 1 later.
